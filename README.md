# MeteoFlow

Для запуска нужны Java 17+, Maven 3.8+ и переменная окружения `YANDEX_WEATHER_API_KEY`
с ключом API Яндекс Погоды, которому доступен REST v2.

Соберите проект через Maven и запустите `com.example.meteo.Main` в IDE.

Введите в консоли широту, долготу и количество суток. Можно использовать точку или
запятую. Enter оставляет значения по умолчанию: Белгород, Россия (`50.5956`, `36.5873`),
прогноз на 3 суток.

После результата введите `д`, чтобы запросить погоду ещё раз, или `н`, чтобы выйти.
